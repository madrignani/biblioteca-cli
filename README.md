# Biblioteca CLI

Aplicação de terminal desenvolvida em PHP para gestão básica do estoque de bibliotecas.
O objetivo do projeto é revisar na prática conceitos fundamentais de POO, persistência em SQL, controle de versão com Git e boas práticas do ecossistema PHP.

Este foi meu primeiro projeto desenvolvido com o código-fonte padronizado em inglês, visando eliminar o uso de código híbrido e aproximar a estrutura dos padrões de mercado.

Desenvolvido por Giovanni de Oliveira Madrignani.




## Funcionalidades

### Gestão de Livros e Autores
- Cadastro de autores
- Cadastro de livros
- Consulta de livros vinculados aos autores
- Edição, listagem e exclusão de livros
